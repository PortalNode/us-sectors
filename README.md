# قطاعات السوق الأمريكي | مؤشرات الشركات

نسخة مطابقة لتصميم موقع «قطاعات السوق السعودي» لكنها تغطي **أكبر 200 شركة أمريكية بالقيمة السوقية** المدرجة في NYSE وNASDAQ، بواجهة عربية كاملة (RTL).

الموقع مبني على GitHub Pages: <https://portalnode.github.io/us-sectors/index.html>

## ما يعرضه الموقع

- **ملخص السوق**: مؤشر S&P 500 (قيمة، تغير يومي، أداء YTD/3م/6م/1س)، اتساع السوق (مرتفع/منخفض/دون تغيير) محسوب من الشركات الـ200، والقيمة المتداولة بالدولار.
- **دليل الشركات**: جدول واحد بأكبر 200 شركة مقسم على قطاعات عربية، مع أعمدة التقييم (PE، PB، ربحية السهم، القيمة الدفترية، عائد التوزيع، نطاق 52 أسبوعاً) والأداء (YTD، 3م، 6م، 1س) والتداول.
- **أسعار حية أثناء الجلسة** (9:30–16:00 بتوقيت نيويورك) من TradingView مع وسائط CORS بديلة من Yahoo Finance، ثم تعود الصفحة تلقائياً إلى لقطة الإغلاق من `data.json`.
- **صفحة نتائج سنوية لكل قطاع** (8 قطاعات) بالرسوم البيانية، من ملفات SEC EDGAR الرسمية (10-K/20-F).
- **صفحة مقارنة النتائج المالية** بين شركات القطاع (إيرادات، أرباح، هوامش، ROE).

## مصادر البيانات

| البيان | المصدر |
|---|---|
| الأسعار، القيم السوقية، المؤشرات، الأداء | TradingView Scanner (america) |
| المؤشر العام | S&P 500 عبر TradingView |
| القوائم المالية السنوية وربحية السهم والقيمة الدفترية | SEC EDGAR `companyfacts` |
| أسماء الشركات بالعربية | جدول `scripts/names-ar.json` المحفوظ |

القواعد المتبعة في التغطية: قائمة الشركات هي أكبر 200 شركة مقيّدة في NYSE/NASDAQ/AMEX (تشمل شركات أجنبية مقيّدة في الولايات مثل ASML والشركات بالADR)، بعد استبعاد أسهم OTC الأجنبية والأسهم المفضلة وشهادات الإيداع، واعتماد الصنف الأعلى سيولة للشركة الواحدة.

## التشغيل والتحديث

- `scripts/build-us-data.mjs` — يبني `dist/data.json` و`dist/financial-map.json` (لقطة أسعار).
- `scripts/build-us-financials.mjs` — يبني ملفات النتائج `dist/<slug>-financials.json` من SEC EDGAR (يتطلب `SEC_USER_AGENT`).
- GitHub Actions:
  - `update-prices.yml`: تحديث الأسعار كل 15 دقيقة أثناء الجلسة الأمريكية وبعد الإغلاق.
  - `update-financials.yml`: تحديث القوائم المالية أسبوعياً (السبت).
  - `deploy-pages.yml`: النشر إلى GitHub Pages عند كل دفعة إلى `main`.

## بنية المجلدات

```
dist/                 الموقع المنشور (index, comparison, صفحات القطاعات, data.json…)

.github/workflows/    النشر وتحديث الأسعار والنتائج
```
